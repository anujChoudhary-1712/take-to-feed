# Content experiment guide

Keep an `experiments/` folder in the local content workspace. Make one dated folder per experiment, place the [experiment log](../assets/starter/experiment.md) there, and attach analytics exports or record their source and collection date. Link back to the original post projects instead of duplicating them.

## Plan a comparable test

| Decision | Possible primary metric |
| --- | --- |
| Which reel opening holds attention? | Viewers remaining at a defined timestamp, if available |
| Which carousel encourages saves? | Saves divided by reach |
| Which post sends readers to a product page? | Tracked visits divided by impressions, with consistent attribution |

Compare within one platform and account when possible. Keep audience, message, and other creative choices as consistent as the platform allows. Record differences in posting time, topic, paid distribution, and audience. Use the same age after publishing for each comparison. Organic posts rarely receive randomized audiences, so treat their differences as directional.

## Read the result

Report the numerator and denominator before computing a rate. Verify that both versions use the same definitions and time window. Distinguish missing metrics from zeros and leave rates blank when the denominator is zero.

Fictional example: Cover A got 12 saves on 600 reach (2.0%). Cover B got 8 saves on 250 reach (3.2%) in the same 72-hour window. B has the higher observed save rate on smaller reach. Repeat the angle on a comparable post before adopting it as the default.
