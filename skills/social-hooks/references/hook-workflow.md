# Hook workflow

Put one copy of the [hook sheet](../assets/starter/hooks.md) beside the post brief. Store recurring voice preferences in a shared brand file and keep a dated hook sheet for each post. Add example URLs, what made the opening work, and the structural idea worth adapting. Use your own wording and original footage.

## Pick an angle

| Angle | Starting point |
| --- | --- |
| Visible result | Show the exact changed state before explaining how it got there. |
| Familiar frustration | Name the moment the reader recognizes and reveal the next useful move. |
| Practical question | Ask a question the post can answer with one example or short sequence. |
| Supported comparison | Show both cases and explain the material difference. |

For a reel, read the first line aloud with its first visual. For a carousel, read the cover at thumbnail size. For a text post, read the opening without the link or attached media. If the topic is unclear, put the subject earlier.

## Compare options

Score clarity, audience relevance, specificity, and payoff separately on a 0–2 scale. A 0 means the element is absent or misleading, 1 means it needs context or revision, and 2 means it works on its own. Drop a hook whose proof or payoff is missing even if its other scores are high. Use scores as editorial notes, then use actual performance if testing the hook.

Example from the fictional Signal Desk demo: “Give every edit note a home” is concise cover copy. “The edit note is at 12:40. Here’s who owns it.” gives a reel an immediate visual cue and matches the timestamp and assignment shown in the demo.
