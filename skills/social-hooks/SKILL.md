# Social Hooks

Use the [hook workflow](references/hook-workflow.md) and copy the [hook sheet](assets/starter/hooks.md) into the local post folder. Read the brief, source material, and any existing reference notes before drafting.

1. Write down the audience, platform, the promise the post can deliver, and where the payoff appears. If the evidence is thin, narrow the promise.
2. Draft distinct angles. Try a visible result, a recognizable problem, or a specific question. Use a proof or comparison angle only when the source supports it.
3. Adapt the opening to the format. For video, give the first spoken line, first visual, and any on-screen copy. For a carousel, give cover copy and the next slide's payoff or setup. For text, give the opening line and the sentence that earns the next read.
4. Use the rubric to compare the options. Return a recommended opening, a backup that tests a different angle, and the source or payoff for each. Append the chosen version and any observed result to the local hook sheet.
