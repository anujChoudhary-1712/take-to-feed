# Short-form production guide

Use one folder per reel. Keep the original talking-head footage in `raw/`, product captures in `screen/`, transcripts and reference notes in `sources/`, the script and edit plan at the project root, and approved exports in `exports/`. Copy the starter files before the first draft. Record any brand preferences and reference links in the script brief. Use filenames that distinguish takes and screen recordings.

## Script the reel

Start with the line and visual that establish the subject. Add only the context the viewer needs to understand the action. Show the action or evidence when it is mentioned. End on the result or one next step. Put screen actions and pickups next to their spoken beat so a creator can record the assets in order.

## Build the edit handoff

Use a separate source in/out for every clip. Record offsets from the original file, including the filename, and mark unknown ranges as pending. Keep source times separate from output times. Review candidate cuts against the footage so they land cleanly on speech and preserve context. If only a transcript is available, mark edit points for review before cutting.

## Review the export

Use the user's editor or existing render project when available. For a vertical master, start with a 9:16 canvas and preview it with the target platform's interface in mind. Keep key captions and UI details away from overlays. Check the first shot on mute, caption spelling and sync, intelligibility with music, and whether the screen proof matches the spoken line. Use music, footage, and fonts the creator can publish. Keep exports versioned when a previous cut is still in review.

For the fictional Signal Desk demo, open on the edit note at 12:40, show the assignment to Leah, then show the resolved state. The demo transcript supplies evidence timestamps. Exact cutting ranges require the source clips.
