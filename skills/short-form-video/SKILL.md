# Short-Form Video

Follow the [production guide](references/production-guide.md) and copy the [starter files](assets/starter) into the local reel folder. Work in script mode when the user has an idea or draft, and edit mode when they have footage or a timestamped transcript.

1. Define the audience, the single payoff, and the target running time. Use the source material to decide what the first shot can show.
2. In script mode, write spoken lines, screen actions, and a pickup list. Mark suggested timings as estimates. Read the script aloud to check that it fits the target.
3. In edit mode, list each source clip and verified in/out points. Keep setup, evidence, and payoff in the cut. Use screen recordings or B-roll where they clarify something the viewer needs to see.
4. Provide caption copy, cover text, and platform caption. Follow the guide to review an export if a renderer or editor is available. Otherwise deliver the recording brief or timestamped edit handoff.
