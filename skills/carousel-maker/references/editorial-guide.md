# Editorial guide

## Choose a slide sequence

| Source material | Sequence |
| --- | --- |
| Recorded product demo | Outcome cover → problem in context → one visible action per slide → result → next step |
| How-to or transcript | Specific promise → setup → ordered steps → what the reader should do next |
| Case study | Result cover → baseline → change → evidence → takeaway |
| Topic or research brief | Specific question → useful answer → supporting examples → practical next step |

Five to seven slides is a useful starting point. Merge slides that make the same point and split slides that ask the reader to follow two actions.

## Write and source each slide

- **Cover.** Name the result or question clearly enough to make sense by itself. If it promises three steps, deliver three.
- **Middle.** Use a headline that names an action or conclusion. Add a brief line of context. A product screenshot should show the control, state change, or result the copy describes.
- **Close.** Resolve the promise and give one action the reader can take. Choose the action based on the brief.
- **Evidence.** Use references such as `sources/demo-transcript.md at 00:12; sources/assigned.png`. If a quote, metric, or customer outcome cannot be verified from the material, revise the slide to describe what can be shown. Label fictional or illustrative material.
- **Visuals.** Crop to the area the reader needs and check that its labels are readable. Use a consistent palette and enough contrast for small screens. If an image adds no information, use a text slide.
- **Captions.** Use the Instagram caption to reinforce the takeaway and write concise image descriptions for each slide. For LinkedIn, give the PDF context and explain why the reader would open it.
